## ⚡ Quick Deploy

```bash
# Clone repo
git clone <repo-url>
cd Langchain-API-new

# Setup environment
cp .env.example .env
# Edit .env sesuai konfigurasi Anda

# Deploy dengan Docker Compose
docker-compose up -d
```

Untuk panduan lengkap, lihat [`DEPLOYMENT.md`](./DEPLOYMENT.md).
